# Lab 07 - Biomechaniczna roślina

Projekt wykonany w Blenderze w ramach laboratorium 07 z Systemów Animacji Komputerowej.

## Opis

Scena przedstawia prosty model biomechanicznej rośliny. Model składa się z łodygi, liści, pierścienia technicznego oraz drobnych elementów mechanicznych.

## Użyte techniki

* Edit Mode
* Extrude
* Loop Cut
* Bevel
* Inset Faces
* Mirror Modifier
* Subdivision Surface
* organizacja obiektów w kolekcji `Roslina_Hero`

## Pliki

* `lab07_roslina_biomechaniczna.blend` - plik źródłowy Blender
* `roslina_hero_07.png` - render końcowy
