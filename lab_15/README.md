# Lab 15 - Neon Rain Walk

Projekt końcowy z przedmiotu Systemy Animacji Komputerowej.

## Opis

Celem projektu jest przygotowanie krótkiej animacji 3D w Blenderze przedstawiającej widok POV osoby idącej nocą przez deszczowe miasto. Scena będzie zawierać mokrą ulicę, neony, przejeżdżające samochody, reflektory oraz deszcz.

## Planowane elementy

- miejski korytarz z budynkami,
- kamera POV z lekkim ruchem chodzenia,
- animowane migotanie neonów,
- mokry asfalt z odbiciami,
- minimum dwa samochody z reflektorami,
- deszcz sterowany skryptem Python,
- końcowy render w formacie MP4.

## Technologia

- Blender
- Python bpy
- Git
- Git LFS dla plików binarnych
