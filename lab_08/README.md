# Lab 08 - Materiały i oświetlenie

Projekt wykonany w Blenderze jako kontynuacja modelu rośliny biomechanicznej z Lab 07.

## Opis

W scenie dodano materiały oraz oświetlenie do modelu rośliny. Zastosowano materiały organiczne, metaliczne oraz świecący element bioluminescencyjny.

## Wykonane elementy

* materiał organiczny dla łodygi i liści
* materiał metaliczny dla detali mechanicznych
* materiał Emission dla świecącego elementu pąk 
* oświetlenie Three-Point Light
* ciemne tło sceny
* render końcowy 1920x1080
