# Lab 06 - Blender GUI

## Temat

Biomechaniczny teren / wejście do podziemnego lasu.

## Opis projektu

Projekt został wykonany w programie Blender z użyciem interfejsu graficznego.  
Celem było przygotowanie prostej sceny 3D z użyciem Object Mode oraz Edit Mode.

Scena zawiera nierówne podłoże, trzy filary biomechaniczne, centralny element przypominający wejście oraz dodatkowe elementy dekoracyjne.

## Użyte funkcje

- nawigacja w 3D Viewport,
- Object Mode,
- Edit Mode,
- przesuwanie, obracanie i skalowanie obiektów,
- Extrude,
- Loop Cut,
- duplikowanie obiektów,
- ustawienie kamery,
- dodanie oświetlenia,
- render do pliku PNG.

## Pliki

- `lab_06_biomechaniczny_teren.blend` - plik projektu Blender,
- `teren_06.png` - końcowy render sceny.
